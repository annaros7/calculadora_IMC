# Calculadora de IMC
A Calculadora de Índice de Massa Corporal (IMC) é uma ferramenta que permite identificar 
se uma pessoa está dentro do peso considerado ideal, de acordo com padrões estabelecidos pela Organização Mundial da Saúde (OMS).

No rodapé da página, há um informativo que explica o que é o IMC, como o cálculo é realizado e apresenta uma tabela com os valores de referência utilizados para a classificação dos resultados.
